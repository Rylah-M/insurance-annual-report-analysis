# 第五阶段验收说明

## 完成内容

1. 自动分析报告 Agent：`backend/agent/report_agent.py`
   - 输入结构化指标库，输出 `analysis_report.json`、`analysis_report.md`、
     `analysis_report.html`，并支持 PDF 下载。
   - 报告包含公司基本情况、业务规模、盈利能力、偿付能力、投资能力、
     风险与复核提示；关键指标自动生成 SVG 图表并嵌入 HTML。
2. 数据库升级：`backend/database.py`
   - 首次启动自动将 CSV 同步为 SQLite `data/database.db`。
   - 三张表：`company_info`、`indicator_data`、`report_info`。
   - 失败时自动回退 CSV，保留既有接口。
3. 报告接口：`POST /api/report/generate`、`GET /api/report/download`、
   `GET /api/report/artifacts`。
4. 智能问答 Agent：`backend/agent/chat_agent.py`
   - 问题理解 → 检索指标库 → 组织上下文 → 回答。
   - 配置 `LLM_API_KEY` 等环境变量后调用 OpenAI 兼容接口，否则使用
     可解释的模板回答，并返回 `source` 数据来源。
5. 前端页面：自动报告、智能问答、项目总览增强。
6. 部署：`Dockerfile`、`docker-compose.yml`，访问 `http://服务器地址:8000`。

## 验收命令

```bash
cd backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

接口示例：

```bash
curl -X POST http://127.0.0.1:8000/api/report/generate \
  -H "Content-Type: application/json" \
  -d '{"company":"中国太保","year":2024}'

curl -X POST http://127.0.0.1:8000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"question":"中国太保综合成本率是多少？"}'

curl -o report.pdf "http://127.0.0.1:8000/api/report/download?company=中国太保&year=2024&format=pdf"
```
